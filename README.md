# Image Gallery - Internship Task 1

🔗 **Live Demo:** [https://sky5532.github.io/CodeAlpha_Task-1-Image-Gallery/](https://sky5532.github.io/CodeAlpha_Task-1-Image-Gallery/)

A responsive image gallery built with HTML, CSS, and vanilla JavaScript.

## Features

- Responsive grid layout that adapt to any screen size
- Lightbox view - click any thumbnail to see it full-screen
- Next/Previous navigation within the lightbox
- Close via the X button or by clicking the dark background
- Smooth hover zoom effect on thumbnails
- Bonus: category filter buttons (All / Nature / People / Places)

## How to Run

1. Download or clone this folder.
2. Open `index.html` in any web browser.
3. No build tools or dependencies required.
